# Quantos Feature Demo Vault

This is disposable sample data for testing the app. It contains two examples of every built-in node type (`note`, `daily`, `task`, `person`, `project`, and `event`) plus the planning/canvas types (`goal`, `sprint`, and `canvas`). The examples show frontmatter properties, tags, links, task states and schedules, reminders, focus logging, tracker values, and canvas cards/edges.

To try it, open Settings › Vault and select this folder as a separate vault. Do not copy these files into your personal vault unless you want the sample records there. It is safe to edit or delete this entire folder.

The event, goal, sprint and canvas node types are extensible app features layered over the custom-node schema. “Two of every type” here means the built-in types and these shipped feature types; arbitrary custom types can be added by a vault owner.
