# Quantos 0.2.3

Build **2026.27.10.15** · October 27, 2026 · Windows x64

- Click a task in Windows or the browser to edit it in a popup. Close with X or Escape to return
  to the same page, scroll position and focus. Android task navigation stays unchanged.
- Sidebar task details move below the title, including dates and priority.
- Failed saves keep the editor open for retry or conflict resolution. Retrying a partially created
  subtask saves the existing task rather than creating a duplicate.
- Local app, browser, personal CLI and agent credentials now have distinct authority. Discovery
  information cannot grant write access. Existing CLI or agent tools may request pairing again;
  approve their connection in the Windows app and manage access in Settings.
- Includes editable task properties and the recent note/folder navigation improvements.

This release contains the Windows portable ZIP and its SHA-256 checksum. The latest public Android
APK remains 0.2.2; private phone builds and signing are unchanged. Shared server deployments are separate.
