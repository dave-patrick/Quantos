Quantos 0.2.0

- Split workspace panes are clearer, the active pane is easier to identify, and each pane has its own close button.
- The right sidebar supports several resizable panels and saves the layout automatically.
- Notes list rows stay on one line. Toggle the preview pane on or off; Quantos remembers your choice.
- Compact My Day task rows keep titles readable, with distinct red P1, orange P2, green P3 and blue P4 priority colors.
- The Windows client removes the unwanted silver frame and supports resizing from every edge and corner. Maximize, restore, hide and reopen now refresh the window layout so controls remain aligned.
- Move a note to the trash directly from its editor, and recover it from Trash until permanently deleted.
- The version label now fits in the bottom-right corner.
