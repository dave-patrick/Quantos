# Website asset origins

- `site/assets/quantos-desk.png`: generated with the built-in image tool from the user-selected Quantos mockup. Background only: charcoal notebooks, mug, open notebook, pen and blue plant; no website text or panels. Real HTML overlays the image.
- Chakra Petch Bold and IBM Plex Mono: Google Fonts source repository, SIL Open Font License files shipped beside the fonts.
- Blue connected-object diagram and source panels are authored HTML/CSS/SVG; displayed schema is illustrative, not a released implementation.
