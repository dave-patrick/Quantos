# Messages

A standalone window for https://messages.google.com/web/ built on Electron (Chromium).
Logins, cookies and cache are kept on disk, so restarting the app keeps you signed in.

## Run it
1. Install Node.js (nodejs.org, LTS).
2. In this folder run: `npm install`
3. Then: `npm start`

## Make an installer (Windows)
`npm run build` — the installer appears in the `dist` folder.
