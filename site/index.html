This repository holds a planned project. There is no application build to download yet. The initial plan targets a single-user, offline-capable Windows workspace; hosting and synchronisation belong to later phases.

The plan: connected objects, readable files.

Quantos is planned as a local-first productivity workspace where notes, tasks, projects and people can be linked without giving up ordinary Markdown files.

  1. Write freely

    Capture a note in Markdown. The plan adds YAML frontmatter for structured fields, so a document can carry a type and useful properties while remaining readable outside the app.

  2. Connect the work

    Link a note to its project, a task to its source and a person to related work. The intended model treats each object as a node, with writing and structured views using the same underlying files.

  3. Choose the right view

    The planned workspace combines free writing with views of tasks, projects and other object types. The initial scope is single-user and offline-capable; hosting, synchronisation and multi-user work belong to later phases.

Project status

This is a build plan, not a released application. The initial architecture targets a local .NET backend with a shared web interface and portable Windows client. No downloadable build, sign-up service or built-in AI is being advertised here.
